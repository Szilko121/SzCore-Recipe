# SzCore Loading Screen

Official loading screen bundled by the SzCore txAdmin recipe.

## Features

- No external CDN dependency
- Native FiveM load progress support
- SzCore visual identity
- Automatic handoff to `szcore_multichar`
- Manual loading-screen shutdown through the existing SzCore character flow

This resource is deployed automatically to:

```text
resources/[szcore]/szcore_loadingscreen
```
